## Findings considered and rejected (do not re-audit)

These were surfaced during the audit and rejected on vetting — recorded so a future
run doesn't re-raise them:

- **Command injection on session-spawn / tmux paths** — routes through `safeSpawn`
  (`packages/core/src/safe-spawn.ts`): binary allowlist + shell-metacharacter
  rejection; tmux targets are regex-validated. No request data reaches a shell.
- **Request-data SQL injection** — none. All 7 `lint-sql-safety.sh` hits interpolate
  Drizzle table-identifier objects or config/test schema names, never request data.
  (Plan 006 annotates them; the injection risk itself is not real today.)
- **Committed `.env` secret** — root `.env` (69 B) is git-ignored and untracked
  (`git check-ignore` confirms); only `*.env.example` is tracked. Clean.
- **CORS / origin handling** — `server-origin.ts` rejects non-Tailscale browser
  Origins (403) and reflects ACAO only for `100.x` origins. Sound anti-rebind
  posture for the network-trust model. Not a finding.
- **Per-request DB connections** — the DB client is a documented startup singleton
  with postgres.js internal pooling, not per-request. Not a finding.
- **Tailscale-ACL-as-trust-boundary (no per-request tokens)** — this is a documented,
  deliberate design decision (`.claude/CLAUDE.md`), not a defect. Plan 004 only closes
  the *asymmetry* where the decrypted-credential route was less guarded than the add
  route; it does not add general request auth.
- **`db:push` / migration policy** — settled project policy (migration-based only);
  not evaluated.

## Direction options (maintainer's call — not ranked against bugs)

Grounded suggestions surfaced by the audit; each would be a design/spike plan, not a
build-everything plan:

- **Productize the web terminal as a phone-first client.** `apps/web` + 4 phone-oriented
  Playwright specs + the in-flight `ios-session-navigation` deep-link work already exist;
  the gap is packaging (auth over Tailscale, onboarding, Swift parity), not capability.
- **Generalize the encrypted store into a multi-provider integrations hub.**
  `encryption.ts` is provider-agnostic; `add-elevenlabs-credential` hand-rolls provider #2
  as a table-mirror. A `provider`-keyed row + integration descriptor absorbs future
  providers cheaply — reshape that in-flight change rather than compete with it.
- **Collapse the two telemetry explorations into one decision.**
  `explore-native-otel-telemetry` and `read-cc-telemetry-from-influxdb` both target killing
  the `token-stream/*` transcript-tail cost hack (also the untested money path, plan 015).
  Two proposals on shared hot files risk divergent half-migrations; run GATE-0, fold into one.
