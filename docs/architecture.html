01The System

Each dev machine runs a nexus-agent daemon with a distinct role. The homelab is the datastore — always on, hosts the central DB, serves queries. The Mac is the notifier — owns TTS, banners, and meeting detection. The TUI queries the homelab as the single source of truth.

03Notification Flow

The NotificationEngine is the single orchestrator — it owns channel routing, meeting detection, banner delivery, and APNs push. TtsService only handles audio.

Incoming event
Local CC hook → Unix socket → lifecycle channel, or remote agent → gRPC StreamEvents. All events enter NotificationEngine.
NotificationEngine — rules + dedup
Per-project rules applied. Duplicates dropped. Mode (Full / NoDuck / System / Silent) determines available channels.
NotificationEngine — meeting check
Mic active or Teams/Zoom/FaceTime window → queued per-project. APNs still fires immediately.
NotificationEngine — channel dispatch
Banner → Nexus-Notifier.app (fire-and-forget) · APNs → Apple Watch HTTP/2 push (fire-and-forget) · TTS → forwards to TtsService
TtsService — audio only
Playback queue (serial, batched). ElevenLabs → system fallback. Media ducking. No channel routing — just plays audio.
Meeting ends → Summary
NotificationEngine flushes queue → per-project banner + TTS: "3 updates for OO while away."

04Services

Both Agents
  • gRPC :7400 — StreamEvents, GetSessions, 18 RPCs
  • HTTP :7402 — REST API (+/ingest on datastore)
  • Socket Listener — /tmp/nexus-agent.sock
  • Health Collector — sysinfo every 5s
  • GitWatch — polls ~/dev/*/.git, 60s
  • SpecWatcher — watches openspec/ dirs, FS notify
  • CredentialPool — OAuth rotation, 5min usage poll
  • SessionPool — warm pre-spawned CC sessions
Mac Only (role: notifier)
  • NotificationEngine — rules, dedup, meeting queue, channel routing, banner dispatch, APNs push
  • TtsService — ElevenLabs / say, playback queue, media ducking (TTS only)
  • EventForwarder — subscribes to homelab gRPC stream
  • MeetingQueue — mic + window detection, per-project hold
Homelab Only (role: datastore)
  • nexus.db — central SQLite, 12 tables, all agents write here
  • POST /ingest — batched insert endpoint for remote agents
