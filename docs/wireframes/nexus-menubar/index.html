A
Identity row · single avatar = homelab. Phosphor gradient when CONNECTED, red when UNREACHABLE. Sub-line shows heartbeat delta + session count, never the Mac itself.
B
Metrics row · CPU and RAM as 10-minute sparklines. Time axis fixed (−10M → NOW). Dot marks current. Phosphor when probe is live, graphite when idle, freezes with STALE overlay when unreachable.
C
Sessions list · only remote (homelab) sessions. Each row: project sigil + title + meta + age. Click → /attach. The local Mac doesn't show up here — if it's running CC, you already know.
D
Action row · three buttons only: ATTACH (open session), NOTIFY (notification history), TTS (audio controls). Contextual relabels in degraded states: DASH→RECON when unreachable; TTS→TTS·FB when fallback active.
E
Alert strip · only renders on actionable errors. Amber=recoverable (ElevenLabs auth), red=critical (homelab offline). Carries a verb on the right.
03INTERACTION SPEC

What every hit does

Keyboard-first. Every interactive region has a hotkey when the panel has focus. MenuBarExtra(.window) gives us focus, keyboard nav, and custom layout for free.

SUMMONglobal

Open the panel

Click the icon. Or ⌃⌥N from anywhere — global hotkey via RegisterEventHotKey.

NAVIGATEfocused

Within the panel

Arrow keys through session list. ↩ = ATTACH to highlighted row (launches Ghostty). esc dismisses. 2-3 trigger NOTIFY / TTS.

ATTACH↩ · single

Launch flow

One subprocess call. Resolves the tmux window name via the local agent (GET /sessions/<id>), then shells out:

open -na Ghostty.app --args -e \
  "ssh -t nyaptor@homelab \
   tmux attach \; \
   select-window -t $name"
SPAWN⌃⌥H

New homelab session

From anywhere: opens Ghostty, SSHes to homelab, runs tmux new-window + claude, hands you the prompt.

TEST GAPnew path

Ghostty launch needs coverage

Existing browser-stream tests still protect /session/[id] on the dashboard, but the menu bar's ATTACH is a fresh subprocess path. Add: mock-Process unit test for the Swift launcher + a manual smoke flow in nexusTests.

SUBSCRIBElive

Real-time stream

Panel opens SSE to http://localhost:7400/events/stream. CPU + RAM update every 5s; session rows update on event.

EVENTS5 types

Event taxonomy

  • RemoteSessionStarted · prepend, animate sigil
  • RemoteSessionEnded · fade, slide out
  • HomelabHeartbeat · update CPU/RAM points
  • HomelabLost · red strip, freeze graphs
  • NotificationFired · pulse NOTIFY badge

04ACTION BUTTON ANATOMY

Three buttons, three jobs

ATTACH, NOTIFY, TTS — each is a single button at rest but reveals a focused secondary surface on hover/click. Designed so primary action is a single click; advanced action is a single modifier or arrow-key.

ATTACH
⌘↩

Single-action. Click → opens Ghostty, SSHes to homelab, attaches to the exact tmux window where the highlighted session is running. No menu, no decisions — you're typing in Claude 200ms later.

RESTING
Phosphor arrow. Disabled (40% opacity) when no session is selected — there's nothing to attach to.
CLICK / ↩
open -na Ghostty.app --args -e \
  "ssh -t nyaptor@homelab \
   tmux attach \; \
   select-window -t <sessionName>"
<sessionName> resolves via GET /sessions/<id> on the local agent — returns the tmux window name (<project>-<timestamp>) that apps/agent/src/routes/sessions.ts:239 created.
RESULT
Ghostty pops into focus with your cursor blinking at the Claude prompt — same tmux window agent created. Type, paste, scroll, Ctrl-B D to detach. The session keeps running on homelab regardless.
NOTIFY
⌘N

History of every notification fired in the current session. Unread badge on the bell when new items arrive. Each row is replayable — click to re-trigger banner or TTS.

RESTING
Bell glyph + amber dot when unread > 0. Dot pulses for 1s when new NotificationFired arrives. Count is implicit (you'll see it).
