Architectural insight. claude-hud exists to reconstruct, from a transcript file it polls, what nx's agent already receives as live hook events over a socket and persists as a queryable subagent tree fanned out to multi-machine Swift dashboards. The transcript-polling mechanism is elegant but strictly redundant for nx — do not adopt the parser. The genuine value is that claude-hud validates nx's display concepts and surfaces two small correctness/polish fixes to the one place nx trusts CC blindly: the statusline binary.
