Nexus / Evolution / Existing ↔ Ideal REV 2026.05.17
A spike on the next refactor

From the mesh you have,
to the spine you want.

The current Nexus is a peer-to-peer mesh of equal agents that could have served a small team. The actual user is one developer with one homelab. This document is the difference between those two systems — a service-by-service spike of what stays, what gets cut, and what fills the gap.

Existing · today
Mesh of equals
  • nexus-agent on every machine (homelab + macbook)
  • peer-to-peer /ws/federation with echo suppression
  • two ingress paths (HTTP /hooks + AF_UNIX)
  • bash listener + bash player + FIFO IPC on Mac
  • web dashboard (nextjs) as universal client
  • nexus-tui as terminal client
  • elevenlabs key encrypted on homelab
  • "credential pool" service mis-used for ElevenLabs only
  • hook payload truncated to RECOGNIZED_EVENTS allow-list
  • 5m idle threshold — bound to old CC session cache
Ideal · north star
Spine + native clients
  • One nexus-agent — homelab only
  • No federation — clients read over SSE/WS
  • AF_UNIX socket-only ingestion
  • Swift menu bar app owns audio + dashboard + settings
  • Native iOS app (separate target) for mobile
  • Web dashboard deprecated
  • ElevenLabs key in macOS Keychain (Swift-owned)
  • cc-credential-manager: writes ~/.claude/credentials.json directly
  • Full hook payload pass-through + schema-drift detector
  • 60m idle threshold — aligned with current CC cache

01 · apps/agent

The daemon's
internals.

The nexus-agent is where the bulk of the structural shift lands. Two ingress paths collapse to one. Three notification channels collapse to text-only dispatch. Peer federation goes away entirely. Two new services appear — a schema-drift detector and a git-project resolver — that surface telemetry the current pipeline silently drops.

file / service
existing · today
ideal · north star
HTTP /hooks routes/hooks.ts
KEEP Cross-machine HTTP ingress for CC hook payloads. Fire-and-forget, always 200. Exists to handle CC sessions on any Tailnet peer.
REMOVE Homelab is the only machine running CC. No cross-machine ingress needed. AF_UNIX socket replaces this entirely.
AF_UNIX dispatcher services/socket-server/dispatcher.ts
KEEP Secondary ingress: ~/.nexus/agent.sock + NDJSON. Kernel-uid auth, ~50× faster than HTTP.
PROMOTE Becomes sole ingress. Move out of services/ into routes/ alongside other entry points; rename to ingress-socket.ts for clarity.
GET /events/stream routes/events-sse.ts
KEEP SSE subscription to lifecycle bus. 30s keepalive. Mac listener's only consumer today.
KEEP Sole client read path in spine model. Swift/iOS/watchOS all subscribe here over Tailnet.
GET /specs/events routes/specs-events.ts
KEEP Translates SpecTransition bus events into wire-format SSE. Consumer is the nextjs dashboard's specs page.
KEEP Consumer shifts from nextjs to Swift dashboard. Wire format stays identical.
PTY attach endpoints /sessions/$id/stream + /interact
KEEP Two WS endpoints: /stream (read-only tail) and /interact (bidi, one-driver-only). Powered by StreamManager.
DROP /interact Keep /stream for Swift dashboard's live PTY pane. Drop /interact — use SSH for typing. Removes a whole class of "who's driving?" race conditions.

KEEP Caller-driven notification ingress. Accepts channel: [tts, desktop, slack]; routes to appropriate handler.

POST /commands/* routes/commands.ts
KEEP kill/restart/attach dispatchers for sessions. Used by TUI.
KEEP Swift app needs the same surface. No protocol changes.
process-watcher services/process-watcher.ts
KEEP 30s pgrep reconcile. Dual purpose: discovers unhooked CC sessions and detects dead PIDs.
ROLE NARROWS With global hooks installed, every CC session emits telemetry. pgrep becomes watchdog only — catches dead/crashed PIDs the Stop hook missed.
spec-watcher services/spec-watcher/
KEEP 60s poll + fs.watch + batch-stagger. Emits SpecTransition events.
KEEP Consumer chain stays: bus → specs-events route → Swift dashboard.
peer-connector services/peer-connector.ts
KEEP WebSocket federation to peer agents. Echo suppression via source: 'peer'. Per-peer 1000-event buffer.

KEEP Write-through Map cache + 60s sweep. Idle threshold 5m (tied to legacy CC cache).

KEEP systeminformation collects every 5s; scheduler persists every 30s. Docker probe backoff 30s → 600s.
KEEP No structural change. Swift dashboard renders this surface natively.

KEEP "Credential pool" service. Mostly used for ElevenLabs key encryption + active-credential-watcher for CC token streams. Misnamed for current scope.
RENAME + COLLAPSE Single file cc-credential-manager.ts. Actively manages ~/.claude/credentials.json — tracks profile expiry, refreshes tokens, swaps on rate-limit. ElevenLabs handling removed entirely (moves to Swift Keychain).
notifications/ — whole dir notifications/manager.ts + channels/*
KEEP Manager + three channel handlers: tts.ts, desktop.ts, slack.ts.
COLLAPSE Single file notifications.ts. Text-only dispatch. All channel logic removed (Swift owns rendering).
notifications/channels/tts.ts channels/tts.ts (~254 lines)
KEEP Calls ElevenLabs API, base64-encodes mp3, emits NotificationFired with audioBase64.
REMOVE Swift app owns synthesis end-to-end. Key in macOS Keychain (proper secret storage). Agent never sees ElevenLabs.
notifications/channels/desktop.ts channels/desktop.ts
KEEP Spawns terminal-notifier for macOS banners (only works when agent runs on Mac).
REMOVE Swift app uses UNNotificationCenter natively. Real click handling, proper notification grouping.
notifications/channels/slack.ts channels/slack.ts
KEEP Webhook POST dispatcher. Channel-acknowledgement tracked in DB.
REMOVE Per your call — Slack drops from the dispatch matrix.
terminal/ terminal/stream-manager.ts + pty-source.ts
KEEP Multiplexed PTY source. Powers /sessions/$id/stream (many readers) and /interact (one driver). Used by nextjs xterm.js viewer.
STREAM-ONLY Keep stream multiplexer. Drop interact codepath. Swift dashboard reads PTY bytes; SSH handles typing.
Pino logging (formalize) logging/ (new)
PARTIAL createLogger from @nexus/core/node exists. Used ad-hoc; no DB sink, no error catch wrapper, no client surface.
FORMALIZE Enforce Pino everywhere. WARN+ sink to new script_errors table. Error capture wrapper for all script entrypoints. Swift app surfaces recent errors in a dedicated pane.
schema-drift detector services/schema-drift.ts (new)
N/A Today: hardcoded RECOGNIZED_EVENTS allow-list. Unknown event types accepted but unknown fields are silently dropped from the dispatcher's parse path.
ADD Store the full raw payload always. Fingerprint per event type (sorted keys hash). On diff, fire HookSchemaDrift event — rate-limited 1 fire per event_type per hour (per your spec). Surfaced in Swift errors pane.
git-project-resolver services/git-project.ts (new)
N/A Session rows store cwd. No derivation of repo identity.
ADD On session_start, run git remote get-url origin from cwd. Parse to { provider: 'github' | 'azdo', owner: ..., repo: ... }. Attach to session row. Enables "all sessions in oo this week" queries.
Note · 01.1
The most subtle migration: hooks were always meant to be the single ingress, but pgrep grew up as a redundancy when hook installation was inconsistent. With global hooks (in your ~/.claude/settings.json), pgrep stops being a discovery primitive and becomes a watchdog — same code, different role. Don't delete it; reframe it.

03 · packages/*

Schema first,
truth lives here.

Sub-agent tree visibility, git project identity, and CC profile tracking all need schema. Three new tables, two modifications, one removal. If the schema doesn't model it, the rest of the pipeline can't surface it.

schema / package
existing · today
ideal · north star
sessions packages/db/src/schema/sessions.ts
KEEP Core session row: id, machine, pid, cwd, status, ccSessionId, agent, model, cost, credentialFingerprint, tmuxSession.
+4 COLUMNS parent_session_id, child_role (sub-agent tree), git_provider, git_owner_repo. Index on parent_session_id for tree queries.
session_events schema/sessionEvents.ts
KEEP Append-only audit trail. metadata = JSON.stringify of recognized fields.
FULL PAYLOAD Store the entire raw hook payload. No allow-list. Schema-drift detector references this row to compute fingerprints.

SIMPLIFY Drop channel column. Drop any audio-related fields. Text-only dispatch record.
health_snapshots schema/healthSnapshots.ts
KEEP Periodic rollup, rawJson column for ad-hoc analysis, 24h default retention.
KEEP No changes.
credential_events schema/credentialEvents.ts
KEEP Ambiguous: was designed for "credential pool" rotation but currently records ElevenLabs swap events.

KEEP Encrypted ElevenLabs API keys, decrypted on synthesis call.

05 · migration

Six phases.
Each shippable alone.

The shift is real but not monolithic. Each phase is independently shippable — if you pause after any one, the system still works. Roughly ordered by leverage × reversibility.

P1
Phase 1 · consolidation

Reap the obvious wins.

Remove dead code and one-off services. None of these change the shape of the system — they just stop carrying dead weight. Largely reversible by git revert. Two items already landed in this session.

DONE retire nexus-register DONE rename nexus-status → nexus-statusline collapse notifications/ to single file collapse credentials/ dir (interim) remove services/peer-connector.ts remove channels/slack.ts bump session-manager idle 5m → 60m
P2
Phase 2 · CC integration

Surface what's already arriving.

The hook payload already carries sub-agent fields, schema can drift undetected, every event has a cwd we could resolve to a git repo. This phase upgrades the agent to use what CC is already giving it.

schema-drift detector + hook_schema_fingerprints table git-project-resolver + sessions schema +2 cols parent_session_id + child_role tracking Pino enforced everywhere script_errors table + DB sink drop RECOGNIZED_EVENTS allow-list (accept all)
P3
Phase 3 · ingress collapse

One door in.

HTTP /hooks becomes the legacy path; AF_UNIX socket is sole ingress. Requires updating the CC hook scripts in your global settings to write to the socket instead of POSTing.

AF_UNIX dispatcher gets full feature parity with /hooks tiny shell helper for hooks: nc -U or shim binary update ~/.claude/settings.json hooks to use shell helper delete routes/hooks.ts after one cycle of running both
P4
Phase 4 · Apple ecosystem

Three targets, one codebase.

XcodeGen manifest is already in place. Build out the iOS and watchOS targets sharing NexusShared. Swift takes ownership of audio synthesis end-to-end. cc-credential-manager ships in parallel — agent actively manages ~/.claude/credentials.json.

xcodegen generate + audit signing settings build NexusShared framework (models, NexusClient, observers) scaffold nexus-ios + nexus-watch entry points Swift owns ElevenLabs synthesis (key in Keychain) cc-credential-manager.ts (writes credentials.json directly) drop notifications/channels/tts.ts + desktop.ts
P5
Phase 5 · web deprecation

Swift reaches parity, web retires.

Until Swift dashboard has every page the nextjs dashboard has (specs, credentials, failures, notifications, projects, sessions, settings, health), the web stays. The moment parity hits, nextjs + dashboard service + Traefik config all come down in one commit.

Swift dashboard reaches feature parity delete apps/nextjs/ delete packages/ui/ delete deploy/nexus-dashboard.service delete deploy/traefik/ delete deploy/nexus-bundle-manager.sh (if web-only)
P6
Phase 6 · final cleanup

Mac stops being a server.

Remove all Mac-side daemon infrastructure. macOS becomes pure Swift app + Tailnet membership. install.sh becomes env-aware (Mac → build Swift app, Linux → build agent + systemd).

delete deploy/com.nexus.agent.plist delete deploy/nexus-notifier.sh + notifier.plist + tts-player.plist delete deploy/nexus-listener.ts (decommissioned) delete deploy/nexus-stub.swift install.sh: env-aware Mac/Linux paths document the spine in docs/ for future reference
Note · 05.1
The phases are roughly ordered by reversibility × leverage. P1 + P2 are cheap and reversible. P3 changes the contract with CC's hook system — harder to roll back without restoring the HTTP endpoint. P4 is the largest chunk of new code; consider it a multi-week effort. P5 + P6 are pure deletion once parity holds.
Note · 05.2
None of this is committed. This document is a spike for your review. The two items marked DONE in P1 actually landed in code (nexus-register retirement + nexus-status rename) and are committable now. Everything else is proposal.
From mesh to spine — a spike.

This is a spike, not a commitment. Every row is a defensible proposal scored against the current shape; verdicts assume the single-developer, single-homelab use case. If the team grows or the topology changes, several REMOVEs become KEEPs again.
