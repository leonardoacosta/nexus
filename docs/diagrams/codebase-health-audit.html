Wave 1 Quick Wins · ~30 min · 5 fixes · zero risk
  • UTF-8 panic fix — floor_char_boundary() in db.rs:1802 (1 line)
  • Mutex swap — std::sync::Mutex → parking_lot::Mutex, remove 3x .unwrap() (3 lines + Cargo.toml)
  • Port bug fix — nexus-status 7401 → 7402 (1 line)
  • Delete 19 orphaned tmp files — 12 in agent, 7 already done in core (rm command)
  • Remove dead toml dep from nexus-core Cargo.toml (1 line)
Wave 2 Architecture · ~4 hours · 4 refactors · low risk
  • Split db.rs into 17 submodules with from_row() pattern (zero breaking changes, 8-step incremental)
  • Move reqwest — relocate query_usage + helpers to nexus-agent (~60 LOC move)
  • Port constants — add DEFAULT_GRPC_PORT / DEFAULT_HTTP_PORT + helpers to nexus-core, all crates reference them (7 files)
  • Atomic symlink swap — temp symlink + rename(2) in credential_pool.rs (10 lines)
Wave 3 TUI Reliability · ~3 hours · 4 fixes · medium risk
  • Spawn SendCommand into separate tokio task (unblocks select loop) (critical — fixes polling stall)
  • Channel capacity 4 → 32 + error surfacing for 4 critical try_send sites (SendCommand, StopSession x2, StartSession)
  • Render cache for stream view — CachedDisplay with dirty flag, O(n) → O(visible_height) per frame (also fixes latent scroll bug)
  • App struct decomposition — extract per-screen state into sub-structs (50 fields → ~20 + screen-specific Options)
Wave 4 Agent Hardening · ~3 hours · 4 fixes · low-medium risk
  • CancellationToken threaded to 5 fire-and-forget tasks (stale detection, event forwarder, notification engine, config watcher, health collector) (uses existing ShutdownCoordinator)
  • Split http_handlers.rs (1,788 LOC) into domain modules (specs, projects, analytics, recommendations)
  • spawn_blocking for sync file I/O in git_watch, server_monitor, spec_watcher, credential_pool (4 services)
  • Subprocess timeouts for bd, git, and openspec calls in HTTP handlers (kill_on_drop + timeout)
