  • 1DOSE BANDEach horizontal band is an agent's active / effect window — not the moment swallowed. Lisdexamfetamine's band spans 7 AM→9 PM because that's how long it's working, so overlaps read as live mechanism, not pill count.
  • 2BAND COLOR = SYSTEMColor encodes the neurochemical system: blue = dopaminergic (Lisdex, Semax), violet = serotonergic (Buspirone, L-Tryptophan), teal = GABAergic / sedative (Guanfacine, Magnesium, Sleep blend, L-Theanine), orange = caffeine.
  • 3AM CLUSTERThe top-left of the grid is a dense blue + orange wash: Lisdex, Semax, and both coffees stack into one dopaminergic / stimulant ramp — the "go" block of the day, visible without reading a single label.
  • 4PM CLUSTERThe bottom-right is all teal + violet: Guanfacine, Magnesium, L-Tryptophan, Sleep blend collapse into the evening wind-down — the at-a-glance proof the sedative load lands after the stimulant load clears.
  • 5COLLISION READWhere a blue band still overlaps a teal band (e.g. Lisdex tail vs Guanfacine onset ~8:30 PM) the user sees a stimulant-vs-sedative overlap window — the exact tension this view exists to surface.
  • 6FILTER CHIPSThe system chips toggle whole color families on/off. Muting Caffeine drops both coffee lanes; muting GABAergic isolates the daytime stimulant story. "Foundational" ships off by default to cut noise.
  • 7NOW-LINEA faint dashed red vertical at the current clock time (~2 PM) crosses every lane, so "what is active right now" is whichever bands the line passes through — here: Lisdex, Coffee Noon, Buspirone PM.
  • 8TAP TO EDITTapping any band opens the dose-detail popover (right). It shows dose, take-time, computed peak + duration, and an Edit-time chip that lets the user slide the actual swallow time and re-render the band.
  • 9NEURO-LOAD STRIPThe strip under the lanes sums active bands per hour into a single curve — two humps: an AM stimulant peak ~10:30 AM and a PM sedative rise after 8 PM, the day's overall pharmacological intensity.
  • 10SPLIT-DOSE LANESAgents taken twice get two bands on one lane (Buspirone 7 AM + 1 PM; Coffee split into AM and Noon lanes) so a divided regimen still reads as one row, not two unrelated entries.
  • 1112-HOUR CLOCKThe ruler and all times use a 12-hour clock with AM/PM (6 AM → 12 AM), matching how the user actually thinks about morning meds vs bedtime stack — no 24-hour military times anywhere.
  • 12DATE STEPPERThe < Thu Jun 19 > stepper walks day-by-day; each day re-lays the same lanes against the same ruler, so week-over-week timing drift (later coffee, earlier Guanfacine) is spottable by flipping dates.
