  • 1SCHEDULE ROWEach row is one med or supplement's plan — frequency, dose times, with-food, reminder, and start date — all editable inline. This is the single source the rest of the app reads from.
  • 2DOSE-TIME EDITTime-slot chips (e.g. 7:00 AM) are tappable 12-hour time inputs — Lisdexamfetamine's slot anchors the early-AM dose so it clears before sleep.
  • 3FREQUENCY RULEThe QD / BID / PRN segment drives how many time-slots render: QD shows one, BID shows two (Buspirone 7 AM + 1 PM), PRN shows "as needed" with no fixed slot.
  • 4PRN = AS-NEEDEDHydroxyzine is PRN — no scheduled slot, no reminder; it shows "as needed · bedtime" and is logged only when actually taken.
  • 5WITH-FOOD FLAGThe with-food toggle (on for Omega-3 + CoQ10) feeds the bioavailability model — fat-soluble doses absorb better with a fatty meal, shifting the PK curve in the neuro-load chart.
  • 6PER-MED REMINDEREach row's bell toggle controls reminders for that med; meds default on, OTC habituals like coffee default off (you don't need a nudge to drink coffee).
  • 7CAFFEINE CUTOFFCoffee is BID with a hard noon second slot — the inline note marks the caffeine cutoff that protects sleep onset, a rule the timeline enforces visually.
  • 8COLOR = SYSTEMThe left border color-codes each row by neuro-system (dopa / sero / gaba / foundation) — the same taxonomy as the neuro-load and dossier views.
  • 9LOG ACTUAL"Today's doses" is the planned-vs-actual surface: checked rows stamp the real take-time (taken 7:04 AM), unchecked rows show upcoming "due" times — the adherence record.
  • 10ADHERENCEThe "6 / 8 logged · 92% this week" readout rolls actual take-times into an adherence stat that the effect-correlation view cross-references against mood/focus logs.
  • 11GLOBAL SETTINGSThe Reminders panel sets app-wide behavior: notify-at-dose-time, snooze interval, and quiet hours (11 PM–6 AM) that suppress late-night pings.
  • 12START / ENDThe "since" column ties each row to the regimen Gantt — start dates here become the bar origins there; ending a med closes its bar.
  • 13ADD-MED FLOW"+ Add med" opens a new row to pick the substance, set frequency + times, and flag with-food — after saving it flows into the timeline, PK charts, and interaction matrix.
