Dismiss / acknowledge
  • 1Cell = pairwise severity Every cell is the interaction grade between its row and column substance; color maps 1:1 to the legend (red major / gold moderate / green beneficial / grey minor).
  • 2Click → detail drawer Tapping any non-trivial cell opens the side drawer (C) with the pair's mechanism and a plain-language recommendation.
  • 3Active-conflicts summary Row A rolls up every conflict in today's logged take-window into one glanceable badge count — the user sees "2 major" before opening the grid.
  • 4Severity filter The chip row scopes the matrix to a single grade (All / Major / Moderate / Beneficial); "All" is the default active state.
  • 5Warn at log-time The matrix is not just a reference — logging a dose that lands a major/moderate cell fires the same warning inline at the moment of entry, not after.
  • 6Two majors total Exactly two red cells per triangle: 9-Me-BC×Lisdexamfetamine (MAOI + stimulant) and 5-HTP×Buspirone (serotonergic stacking).
  • 7Beneficial cell is green Guanfacine×Lisdexamfetamine reads green — the alpha-agonist smooths the stimulant's cardiovascular edge, a desirable pairing rather than a warning.
  • 8Noon-coffee conflicts Coffee (noon) carries gold cells against Guanfacine and Hydroxyzine: late caffeine opposes the PM sedative / sleep-onset arm of the stack.
  • 9Catecholaminergic cluster L-Tyrosine and the two coffee entries all flag moderate against Lisdexamfetamine — the additive AM catecholaminergic load shows as a band down column 1.
  • 10Symmetric matrix Interaction grade is order-independent, so the grid is symmetric; only the lower triangle is filled and the upper left grey for a cleaner read.
  • 11Self diagonal The diagonal is rendered as inert "self" cells — a substance never conflicts with itself, so those cells are non-interactive.
